# Kleines Schäferrad — digitale Rekonstruktion

Digitale Bestandsaufnahme und evidenzbasierte 3D-Rekonstruktion des **Kleinen Schäferrads** bei Möhrendorf/Oberndorf.

## Aktueller Zustand

**PRE-DISASSEMBLY BASELINE — IN PROGRESS**

Dieses Projekt basiert ausdrücklich auf **allen** verfügbaren Quellen:
- Feldwissen und Projektkontext,
- 30 fotografierten Zeichnungen/Feldaufnahmen,
- aktuellen Fotos des eingebauten Rads,
- Scaniverse PLY + GLB,
- späteren LiDAR-/Photogrammetrie-/Gaussian-Splat-Captures,
- Handmessungen während der bevorstehenden Demontage,
- öffentlichen Kontextquellen.

Die Punktewolke ist nur eine Evidenzklasse unter mehreren.

## Prinzip

> Keine hübsche Halluzination eines historischen Rades, sondern eine rekonstruierbare Geometrie mit Provenienz.

Raw Evidence, mechanische Rekonstruktion, reale Oberflächen und atmosphärische Site-Repräsentation bleiben getrennte Schichten.
