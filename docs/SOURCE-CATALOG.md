## 4. Projektwissen

Zum Evidence Scope gehören zusätzlich die im Projektgespräch festgehaltenen Randbedingungen:
- saisonale Demontage steht unmittelbar bevor,
- Ziel ist erstmalige vollständige digitale Rekonstruktion,
- das Modell muss zerlegbar/assemblierbar sein,
- historische Unterlagen können dem heutigen Reparaturzustand widersprechen,
- schlechte/partielle Scans bleiben als Raw Evidence erhalten,
- zukünftige Einzelteilscans und Demontagefotos werden auf stabile Component-IDs registriert.
