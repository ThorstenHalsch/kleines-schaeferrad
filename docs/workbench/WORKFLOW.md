# Field workflow alpha

Source base: dd0cd480a4f509a1137ca19a7f9075a8aba0c30a. Date: 2026-10-07.

1. SELECT: search local names or choose a large part button; alternatively pick a mesh or pin. Selection includes an ontology family and optional historical slot, never an invented physical identity.
2. UNDERSTAND: inspector separates original claims, historical parameters, unmeasured geometry placeholders, conflicts and evidence. Original evidence images are linked directly.
3. QUESTION: one primary GAP with capture instruction and acceptance evidence. Other relevant gaps remain selectable.
4. CAPTURE: choose measurement, observation, identification, expert narrative or risk; guided steps record context, evidence and review. A/B choice is a field observation, not automatic adjudication.
5. UPDATE: preview explicitly states which claim/conflict/GAP is addressed and whether the record supports, challenges or only contextualizes it. Save as an unreviewed local observation. Counts and task status change to 'evidence pending review'; baseline claims and gaps stay unchanged.
6. RESUME/EXPORT: draft and selection survive reload. Export carries all records and inline photo bytes; import validates schema and merges IDs without overwriting conflicts. Local storage errors remain visible and export stays available.

Navigation: Rad → selected Teil → Frage → Erfassen → Prüfen → lokal gesichert; separate Zeichnungen and Protokoll. No requirement to use orbit or small mesh targets. Capture is one visible step at a time. Demontage context includes event, partner, orientation, before/after media and storage location. No capture is a fabrication approval.
